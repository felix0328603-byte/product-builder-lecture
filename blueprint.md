# Project Blueprint

## Overview

This project is a simple lottery number generator. It generates six unique random numbers between 1 and 45.

## Features

*   Generates six unique random numbers.
*   Displays the numbers in a visually appealing way.
*   Modern and responsive design.

## Current Plan

*   Create the HTML structure for the lottery number generator.
*   Style the lottery number generator using CSS.
*   Implement the JavaScript logic to generate and display the lottery numbers.
